# 录屏与提交指南

建议录制约 10–12 分钟，留在 15 分钟上限以内。

1. 研究问题（1 分钟）：为什么关注 Agent 通过经验改进；本次验证的是上下文经验积累，不是模型权重训练。
2. 原论文目标（1 分钟）：Formula 基线与 ACE 对照；明确当前模型与数据规模不同，不能直接比较绝对分数。
3. 架构（1.5 分钟）：Generator 作答，Reflector 分析反馈，Curator 更新 Playbook；测试时冻结手册。
4. 实验设计（1.5 分钟）：三组配置、三个抽样种子、50/30/100 划分、同种子共享相同题目；解释训练标签与测试标签的用途不同。
5. 结果（2 分钟）：使用最终生成的均值、标准差和逐种子数据，不沿用试跑数字。真实结果没有提升也应如实呈现。
6. 费用与机制（1 分钟）：区分适应成本和最终测试成本，区分最大反思轮数和实际轮数。
7. 局限与演示（2 分钟）：展示 README、一个经验手册及原始日志。说明模型替换、样本重叠、API 随机性与精确匹配评分。
8. 结论（1 分钟）：回答两个研究问题，解释哪些结论受证据支持，哪些还不能确定。
